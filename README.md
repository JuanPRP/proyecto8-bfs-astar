# Proyecto 8: Búsqueda de caminos en mapas de cuadrícula (BFS y A*)

Estructura de Datos · Universidad Piloto de Colombia, Seccional del Alto Magdalena · 2026-II

Integrantes: 
Juan Reyes Pava
Helmut Bode Diaz
Gabriel Beltran Villamizar

Un robot debe encontrar el camino más corto en una cuadrícula con obstáculos.
El mapa se modela como un grafo no dirigido y se resuelve con BFS y A*,
usando estructuras implementadas desde cero (Nodo, Cola, MonticuloMin, Grafo).

Estado: Entrega 1 (modelado y diseño). Nodo y Grafo implementados;
Cola, MonticuloMin y los algoritmos se agregan en la Entrega 2.

Requisitos: Python 3.11+
